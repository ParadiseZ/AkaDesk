# 安卓主控录屏复刻设计与验收

参考：`D:\AdminFiles\Download\record-10111006.mp4`，约 182 秒。实现范围以 2026-10-11 用户确认的“先复刻可支持的功能，保留设计和入口”为准。中转暂不实现，原录屏中仅提示“敬请期待”的页面不作为当前功能。

## 当前实现

| 录屏功能 | 当前实现与边界 |
| --- | --- |
| 右侧操作栏 | 操作、键盘、显示桌面（Win+D）、所有窗口（Win+Tab）；操作面板内分显示、安全、外设、更多、系统操作 |
| 顶部快捷按钮 | 退出、旋转、手机声音、仅观看、小窗；可隐藏小窗快捷按钮 |
| 屏幕触控 | 视频内绝对坐标点按、拖动；黑边不注入；缩放后按实际显示区域反算坐标 |
| 鼠标指针 | 相对移动、轻点左键、长按拖动、双指滚轮、捏合缩放；按住左侧右键区可操作右键；支持调整速度 |

| 实体外设 | Android 枚举连接的键盘/鼠标/手柄；现有物理键盘回传及鼠标位置、左右键、滚轮输入；手柄转发入口禁用 |
| 按键映射 | 默认方案及新建/切换方案，每方案最多 30 个按键或组合键；浮动按钮按住发送、拖动保存位置；位置随方案独立保存；大小/透明度可调 |

| 安全 | 手机声音、电脑静音与恢复、仅观看输入暂停、前台文字剪贴板同步、结束连接后锁屏 |
| 系统快捷操作 | 锁屏、任务管理器、重启、关机；电源操作/锁屏提供明确确认；仅允许固定操作，不能执行自定义命令 |
| 文件传输 | 系统文件选择器发送照片/视频或文件，浏览电脑共享目录并下载到手机选择的位置；进度、取消、已发送/已接收/失败历史、清空历史 |
| 网络状态 | WebRTC 原始统计的 RTT、解码耗时、FPS、接收码率、累计丢包率、地址、直连/中转类型、编解码器、画面尺寸、时长；缺失指标显示“—” |

“自动”当前是固定兼容预设，未实现按网络带宽自动调整编码参数。目标 90/120 帧不代表设备能持续达到该帧率，实际速度以网络页统计为准。编码能力、帧率、分辨率均受电脑编码器及手机解码器限制。

仅观看暂停鼠标、触控及键盘输入，电脑端同样拒绝注入，并释放已按下的输入；已在可靠通道中排队的输入会被确认而不执行，以便关闭仅观看后继续使用通道。此开关不撤销已配对授权，也不替代连接授权。

## 保留入口与后续设计

这些能力以关闭、不可操作的入口呈现，注明启用所需条件；没有虚假的“已启用”状态，也不会请求相应 Android 权限。

| 功能 | 入口 | 后续基础设施与契约 |
| --- | --- | --- |
| 自动解锁 | 安全 | Windows 后台服务、Credential Provider/安全桌面处理；明确单独授权与撤销；敏感凭证采用系统安全存储，不经普通文本输入通道模拟登录 |
| 防窥 | 安全 | Windows 服务和虚拟/物理显示控制；进入/退出可恢复，服务崩溃和客户端失联也要恢复物理显示 |
| 虚拟显示器 | 显示 | 虚拟显示驱动安装、枚举、生命周期和恢复；扩展显示标识、选屏捕获与输入坐标契约；多显示器不能只增加 UI 下拉框 |
| 麦克风转发 | 外设 | Android 录音授权、上行 Opus 音轨、Windows 虚拟麦克风；与电脑下行声音分开；停止/失联撤销录音 |
| 手柄转发 | 外设 | Android 轴/按钮及设备变化事件、Windows 虚拟手柄驱动；独立连接与释放契约，断开回到中立状态 |
| 中转连接 | 更多 | TURN 服务、认证、区域选择、连通性探测、ICE 配置及直连失败策略；网络统计保留 relay 类型显示，但当前 RTC 配置不提供 TURN |

后续由 Host 上报每项能力及不可用原因，客户端据此启用现有入口。驱动安装/服务配置、权限授予、运行状态三者分开；UI 开关只在 Host 明确确认后生效。

## 数据与生命周期

### 工具通道

复用已认证 WebRTC peer 新增有序可靠 DataChannel，label 为 `tools`，protocol 为 `akadesk.tools.v1`。数据经 DTLS/SCTP 传输，不另开未认证的文件或命令端口。

请求结构：`{id, session, op, args}`；成功返回 `{id, session, data}`，失败返回 `{id, session, error}`。Host 校验绑定的当前会话、原始控制授权、单调递增请求编号；旧会话和重放请求不得执行。会话锁覆盖实际操作，避免停止/替换后继续写入。

操作包括 `status`、`view_only`、`set_video`、`clipboard_enable/get/set`、`lock_after`、`system`、`list`、`upload_begin/chunk/commit`、`download_begin/chunk`、`cancel`。最多 8 个客户端待确认请求，消息上限 64 KiB，15 秒确认期限。修改操作不自动重试，超时不能宣称执行失败或成功。

工具通道和输入通道必须在 PeerConnection 释放前，先在 Android 主线程注销 observer、关闭和释放。真机验收发现异步排队到 PeerConnection 销毁之后再调用 `unregisterObserver` 会卡住主线程，本次已修正这一释放顺序。

### 文件

- 默认电脑共享目录：`%USERPROFILE%\Downloads\AkaDesk`；本机管理员/测试启动可通过 `AKADESK_SHARED_DIR` 指定目录。
- 下载只读取该目录以内的规范路径，拒绝父级穿越、绝对路径、盘符及越界符号链接。
- 每块 16 KiB，经 Base64 传输；以确认后的偏移推进，文件上限 4 GiB，单方向最多 4 个活动传输。超过限制显示失败原因，不静默忽略。
- 上传写入独立 `.part-*` 临时文件；长度一致并同步后提交；提交使用不覆盖已有目的文件的创建操作。
- 手机经 Storage Access Framework 选择读取与保存位置；未知长度的输入先在私有缓存中读取并校验上限。
- 取消、会话关闭和 60 秒无活动后清理未完成传输；关闭时释放文件句柄并删除上传临时文件。下载失败删除手机端创建的未完成文档（取决于提供者是否允许删除）。
- 历史只记录传输名称、长度、方向、状态和时间，保留最近 100 条已结束记录；不保存文件内容和 WebRTC 凭证。

### 输入和前后台

视频、面板与键盘的本地编辑区域分离。打开面板、切换方案/输入方式、进入小窗、退到后台、仅观看和断开都会释放按下的按键、鼠标键及触点。背景或小窗不发送输入，物理键盘在本地编辑时不透传。

触点帧扩展 `proto/input.proto`，不改变已有字段编号。Windows 检查完整活动触点集合与 phase，注入失败取消旧触点；抬起使用上次注入位置，避免 Windows 拒绝变更位置的 UP 帧。

剪贴板仅用户主动开启后在前台同步文字，默认关闭。初次读取建立基线，不覆盖手机原内容；忽略回声；读取期间手机发生新复制时，丢弃旧的轮询结果。系统后台剪贴板权限限制不通过后台服务绕过。
