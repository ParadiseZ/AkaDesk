# M8 诊断与稳定性实现与验收记录

日期：2026-10-11。接续 M7，下一里程碑为 M9 文件传输。

## 1. 已完成

- `proto/ipc.proto` 增加 `DiagnosticEvent` 元数据与 `DiagnosticSnapshot`。保留旧事件字段号，Rust 的 `DiagnosticEntry` 为兼容别名。
- Runtime 记录连接建立、中断、恢复、超时、媒体降级、显示和声音恢复、会话清理等关键事件。状态来自真实 Session、Transport、Video 和恢复结果；独立故障源全部恢复后才退出 `DEGRADED`，旧会话回调不能改变新会话健康状态。
- `DiagnosticsResponse` / `DiagnosticsChanged` 同时传递近期事件及固定摘要。Shell 映射为简短中文，Vue 诊断页展示状态、最近错误/提醒、连接异常、恢复与结束结果；默认只显示错误与提醒，可切换全部关键事件。
- 诊断导出通过真实 Tauri 命令写入应用数据目录的 `diagnostics/`，使用唯一文件名，不覆盖旧报告。导出只包含运行状态、能力摘要、固定诊断摘要及最多 40 条关键事件。
- Host 子进程异常退出后由现有监督器重新启动；新增代次识别，每次观察到重启记录一条提醒。桌面应用仍运行时保留之前的固定诊断摘要；不把旧会话自动重新启动。

主要入口：`desktop/host/runtime/src/diagnostics/`、`desktop/host/ipc/src/diagnostics.rs`、`desktop/src-tauri/src/state/`、`desktop/src-tauri/src/diagnostics/`、`desktop/ui/src/pages/DiagnosticsPage.vue`。

## 2. 精简日志规则

- Runtime 近期事件上限 40 条；同级别、代码及会话在相邻 30 秒内重复时合并次数和末次时间。重复清理失败不逐次发送通知，不逐次输出 stderr。
- 最近错误、提醒、降级、显示恢复、声音恢复及会话结束摘要独立保留，不随近期事件淘汰。
- Shell 对相同级别/代码 30 秒内只写一次；Host 事件按事件 ID 去重；内存日志摘要最多 50 条。
- 桌面日志按日期保存；单文件达到 1 MiB 后轮换到一份 `.previous.log`。不删除其他日期文件，也不维护海量历史追踪。
- 默认事件和导出不包含验证码、配对令牌、设备名称/地址、SDP、ICE 候选、媒体数据或输入文本。用户提示使用固定映射，不拼接原始系统错误。
- Android 不再逐次输出视频/传输统计与候选发送成功记录；重连只记录首次中断和确认恢复，保留必要状态变化。统计仍用于媒体判断，没有删除功能数据流。

## 3. 恢复与超时

- 手机控制连接恢复时绑定新的连接 ID，保留原会话和 WebRTC；旧连接结束回调不能断开替代连接。电脑只接受当前绑定连接的心跳，超过 30 秒未刷新则结束会话并清理。手机沿用 1/2/4/8 秒退避和 30 秒恢复期限。
- 桌面 IPC 单次请求具有 5 秒整体期限，部分帧可继续读取；失败后关闭该客户端并重新连接。Windows 非阻塞管道暂时没有数据的空读取不能当作完整 EOF。订阅读取仍保持原阻塞契约。
- Shell 状态同步失败采用 4/8 秒等待，成功恢复为 2 秒正常轮询；日志只记录失联/恢复转换。超时写操作不自动重放。
- 结束会话时尝试释放输入、恢复声音和显示、停止媒体并清理设置。恢复失败保留记录供下一次重试；声音工作线程已退出或显示控制尚未准备时，也不能把仍存在的启动恢复记录误报为成功。
